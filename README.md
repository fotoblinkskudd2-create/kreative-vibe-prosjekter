# kreative-vibe-prosjekter

100+ ideelle prosjekter, musikkidéer, satire prosjekter, videoer og Vibe-kort apper.
Inkluderer prototyper, salgsmateriell og klar-til-bygg info.

## Innhold

| Mappe | Hva | Task |
|---|---|---|
| [`apps/StressGuardian/`](apps/StressGuardian/) | Mac menubar-app: OpenClaw multi-agent stress-vakt, panikk-intervensjon, Base44-vibe, iCloud. Komplett Swift-kode + Xcode-instruks. | 1 |
| [`agents/eu_problem_lab/`](agents/) | Multi-agent (Researcher→Analyst→Pitcher→Executor) for EU/globalt problem. Markdown + HTML/PDF + Notion. | 2 |
| [`agents/verdi_dashboard/`](agents/) | Skanner Notion/GDrive/lokale mapper → mønstre, ROI, verdirapport + neste tasks som dashboard. | 3 |
| [`agents/idea_to_prototype/`](agents/) | Idé → full prototype: kjørbar app + landingsside + monetiseringsplan. | 4 |
| [`apps/VibeCatalyst/`](apps/VibeCatalyst/) | Base44 vibe-app → Mac + iOS (Catalyst) med RevenueCat, push og offline. | 5 |
| [`agents/meta_agent/`](agents/) | Master meta-agent: leser alle inputs, genererer og kjører neste tasks automatisk. | 6 |

## Kom i gang

- **Python-agentene** (`agents/`): se [`agents/README.md`](agents/README.md) —
