# kreative-vibe-prosjekter
100+ ideelle prosjekter, musikkidéer, satire prosjekter, videoer og Vibe-kort apper. Inkluderer prototyper, salgsmateriell og klar-til-bygg info. Laget for brukeren.

## Prosjekter

- [**VIBESMIA**](vibesmia/) — Den autonome kreative smia: et multi-agent-system
  som forvandler rå idéer til produksjonsklare leveranser via
  Spenningsprotokollen (produktiv uenighet i stedet for konsensus),
  tre-lags hukommelse og en kjørbar demo uten avhengigheter.
  Se [arkitekturen](vibesmia/docs/ARKITEKTUR.md).
