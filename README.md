# kreative-vibe-prosjekter
100+ ideelle prosjekter, musikkidéer, satire prosjekter, videoer og Vibe-kort apper. Inkluderer prototyper, salgsmateriell og klar-til-bygg info. Laget for brukeren.

## Prosjekter

- [`art-generator/`](art-generator/) — AI art generator: lag bilder fra tekstprompter, behold favoritter, fjern det du ikke liker, og la AI generere varianter ("consorts") av bildene du beholder. Se [art-generator/README.md](art-generator/README.md) for oppsett.
- [`vibe-cards-prototype/`](vibe-cards-prototype/) — Fullstack prototype: Vibe Cards - stemningskort med auth, CRUD-API og minimalistisk UI.
- [`problemknuser/`](./problemknuser) — Gamifisert problemløser-app (HTML/CSS/JS). Skriv inn et problem, få et perspektiv-triks og en 3-stegs handlingsplan, samle XP, level og streak.
- [`alex-civilian-field-lab/`](alex-civilian-field-lab/) — Civilian product scoring and prototyping toolkit.
- [`shared/`](shared/) — Shared utilities used across all projects to reduce code duplication.
