# 🎨 Kreative Vibe-Prosjekter

100+ idéer for prosjekter, musikk, satire, video, kunst og Vibe-kort-apper — med fungerende prototyper, salgsmateriell og klar-til-bygg-info.

## 📂 Struktur

| Mappe | Innhold |
|---|---|
| [`idebank/`](idebank/) | 100+ idéer sortert i fem kategorier, hver med verdi-notat og vanskelighetsgrad |
| [`prototyper/`](prototyper/) | Fungerende prototyper — åpne `index.html` rett i nettleseren, ingen installasjon |
| [`salg/`](salg/) | Pitch-dokumenter og salgsmateriell klare til bruk |
| [`skriving/`](skriving/) | Satire, tekster og skriveprosjekter |

## 🚀 Kom i gang

1. **Bla i idébanken** — start med [`idebank/README.md`](idebank/README.md) for oversikt
2. **Test prototypene** — dobbeltklikk på `prototyper/vibe-kort/index.html` eller `prototyper/blinkskudd/index.html`
3. **Velg et prosjekt** — hver idé har et "klar-til-bygg"-nivå: 🟢 kan bygges i kveld, 🟡 en helg, 🔴 større løp

## ✨ Prototyper som funker nå

- **Vibe-kort** (`prototyper/vibe-kort/`) — kortstokk-app med 60+ kreative prompts i fire moduser: Skap, Skriv, Spill, Tenk. Trekk et kort, få en vibe.
- **Blinkskudd** (`prototyper/blinkskudd/`) — daglig fotoutfordring-generator. Ett tema, tre kreative begrensninger, streak-teller.

Alt er laget som selvstendige HTML-filer — null avhengigheter, null byggverktøy, bare åpne og bruk.
