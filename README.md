# kreative-vibe-prosjekter

100+ idealistiske prosjekter, musikkidéer, satireprosjekter, videoer og Vibe-kort-apper. Inkluderer prototyper, salgsmateriell og klar-til-bygg info. Laget for brukeren.

## Prosjekter

### [`vibe-kort/`](./vibe-kort) — Vibe-kort

En kortstokk-app med 100 originale, konkrete idéer fordelt på fire kategorier: idealistiske prosjekter, musikkidéer, satire og video. Trekk et kort, snu det, lagre favoritter og eksporter et pitch-ark i Markdown — rett fra nettleseren, uten server eller build-steg.

```
open vibe-kort/index.html
```

Se [`vibe-kort/README.md`](./vibe-kort/README.md) for bruk og [`vibe-kort/DESIGN.md`](./vibe-kort/DESIGN.md) for designrefleksjonen bak appen.
