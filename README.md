  2. [Test-Heal Loop](self-improving-loops/02-test-heal-loop/README.md) — testfiks → mønsterbibliotek (`/heal`)
  3. [Prompt-Optimizer Loop](self-improving-loops/03-prompt-optimizer-loop/README.md) — eval-drevet promptforbedring (`/optimize-prompt`)
  4. [Content-Factory Loop](self-improving-loops/04-content-factory-loop/README.md) — engasjementsdata → bedre briefs (`/content`, `/content-retro`)
  5. [Bug-Harvest Loop](self-improving-loops/05-bug-harvest-loop/README.md) — feil → fiks + test + vaktregel (`/harvest`)
