# kreative-vibe-prosjekter
100+ ideelle prosjekter, musikkidéer, satire prosjekter, videoer og Vibe-kort apper. Inkluderer prototyper, salgsmateriell og klar-til-bygg info. Laget for brukeren.

## 🧭 Rammeverk for idéutvikling

Alle idéer i dette repoet kjøres gjennom [rammeverket for idé-til-gjennomføring](rammeverk/README.md):

1. [Idéklargjøring](rammeverk/01-ideklargjoring.md) — konsept, mål og målgruppe
2. [Planlegging og strategi](rammeverk/02-planlegging-og-strategi.md) — plan, ressurser, milepæler
3. [Gjennomføring](rammeverk/03-gjennomforing.md) — prioritering, handlingslister, hindringer
4. [Kvalitetssjekk](rammeverk/04-kvalitetssjekk.md) — suksesskriterier, evaluering, læring

Start en ny idé: opprett `prosjekter/<idénavn>/` og kopier inn [malene](rammeverk/maler/).
