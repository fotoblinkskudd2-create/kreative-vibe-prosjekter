# kreative-vibe-prosjekter
100+ ideelle prosjekter, musikkidéer, satire prosjekter, videoer og Vibe-kort apper. Inkluderer prototyper, salgsmateriell og klar-til-bygg info. Laget for brukeren.


## Prosjekter

- [`alex-civilian-field-lab/`](alex-civilian-field-lab/) — Civilian field-lab pipeline (Python). Se [alex-civilian-field-lab/README.md](alex-civilian-field-lab/README.md).
- [`art-generator/`](art-generator/) — AI art generator: lag bilder fra tekstprompter, behold favoritter, fjern det du ikke liker, og la AI generere varianter ("consorts") av bildene du beholder. Se [art-generator/README.md](art-generator/README.md) for oppsett.
- [`vibe-cards-prototype/`](vibe-cards-prototype/) — Vibe Cards fullstack prototype (Node.js). Se [vibe-cards-prototype/README.md](vibe-cards-prototype/README.md).
- [`problemknuser/`](./problemknuser) — Gamifisert problemløser-app (HTML/CSS/JS). Skriv inn et problem, få et perspektiv-triks og en 3-stegs handlingsplan, samle XP, level og streak. Se prosjektets egen README for hvordan du kjører den.
