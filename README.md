# kreative-vibe-prosjekter
100+ ideelle prosjekter, musikkidéer, satire prosjekter, videoer og Vibe-kort apper. Inkluderer prototyper, salgsmateriell og klar-til-bygg info. Laget for brukeren.

## Prosjekter

- **[sonisk-kunst](sonisk-kunst/)** — lyd → algoritmisk kunst. Egen DSP-pipeline
  (STFT, chroma, onsets, tempo, toneart) på ren numpy/scipy, tre kunstmotorer
  (mandala, flowfield, particles), harmonisk fargelogikk langs kvintsirkelen,
  pluss live nettleserversjon med mikrofon. Verifisert ende-til-ende, se `sonisk-kunst/demo/`.
