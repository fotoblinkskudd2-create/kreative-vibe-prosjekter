# kreative-vibe-prosjekter
100+ ideelle prosjekter, musikkidéer, satire prosjekter, videoer og Vibe-kort apper. Inkluderer prototyper, salgsmateriell og klar-til-bygg info. Laget for brukeren.

## Struktur

Prosjektene er organisert i fem kategorier, hver med tre undermapper:

- [`ideelle-prosjekter/`](ideelle-prosjekter/)
- [`musikkideer/`](musikkideer/)
- [`satire-prosjekter/`](satire-prosjekter/)
- [`videoer/`](videoer/)
- [`vibe-kort-apper/`](vibe-kort-apper/)

Hver kategori har:
- `prototyper/` – tidlige utkast og funksjonelle prototyper.
- `salgsmateriell/` – materiale for å presentere prosjektet (pitch, brosjyrer, skjermbilder o.l.).
- `klar-til-bygg/` – ferdig spesifiserte prosjekter klare for utvikling/produksjon.
