# De fem beste vibe code full-stack appene

Fem app-idéer i din stil: praktisk, norsk, AI-drevet, «tankens kraft», anti-BS, rolig nordisk design – og fokus på ekte norske problemer (psykisk helse, strømpriser, ensomhet, økonomi og Vestland-vær).

Alle er laget for standard vibe-stack og kan bygges på en helg:

- **Next.js (App Router)** + TypeScript
- **Tailwind CSS** + shadcn/ui
- **Supabase** (auth + Postgres + RLS)
- **Vercel** (deploy)

Enkle sider (4–6), mobil-first, rolig nordisk estetikk: dempede blå/grå/grønne toner, mye luft, myke runde hjørner, ingen støy.

## Appene

| # | App | Problem den løser |
|---|-----|-------------------|
| 1 | [SinnRo](01-sinnro.md) | Psykisk uhelse, vinterdepresjon og stress – daglig støtte uten å føles klinisk |
| 2 | [StrømSmart](02-stromsmart.md) | Høye og volatile strømpriser – oversikt og smartere forbruk |
| 3 | [NaboHjelp](03-nabohjelp.md) | Ensomhet og praktiske hverdagsbehov i nabolaget (Bergen/Askøy) |
| 4 | [ØkoBalans](04-okobalans.md) | Privatøkonomi-bekymring – oversikt og tankekraft tilbake |
| 5 | [VærKlar](05-vaerklar.md) | Ekstremvær og klima-adaptasjon på Vestlandet – mental og praktisk beredskap |

## Slik bruker du dem

1. Åpne fila for appen du vil bygge.
2. Kopier vibe-prompten rett inn i Cursor, Bolt, Lovable eller Base44.
3. Bruk datamodellen og MVP-sjekklista i fila som fasit underveis.

Hver fil inneholder: problembeskrivelse, komplett vibe-prompt (klar til å lime inn), foreslått datamodell og en MVP-sjekkliste.
