# Ukens Geniale AI-Kunst-Oppfinner

Ukentlige konseptdokumenter med research-plan, bygget på inputs og minner fra
hele repoet (art-generator, vibe-cards-prototype, problemknuser,
alex-civilian-field-lab, shared/).

Hvert dokument inneholder: ukens oppfinnelse, kildegrunnlag, scoring av fem
kandidater med field-lab-formelen (`sales*0.30 + speed*0.20 + ip*0.20 +
pain*0.20 + safety*0.10`), en 14-dagers research-plan, budsjett, risiko,
KPI-er og salgsvinkler.
