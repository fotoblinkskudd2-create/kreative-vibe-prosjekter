# Musikkidéer

Idéer, tekster og konsepter for musikk.

- `prototyper/` – demoer, utkast til tekster/melodier og tidlige opptak.
- `salgsmateriell/` – cover-art, pitch-tekster og annet materiale for distribusjon/markedsføring.
- `klar-til-bygg/` – ferdig spesifiserte låter/prosjekter klare for produksjon eller innspilling.
