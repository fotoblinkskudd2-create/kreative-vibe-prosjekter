# 100 vibe-code-prosjekter fra GitHub-universet

Oppdrag for **github-speider** (finn og vurder) og **byggmester** (bygg).
Kjøres i bolker på 10. Speideren finner beste faktiske repo/ressurs per idé og setter
byggbarhetsscore; byggmesteren bygger de best egnede — eller gjenskaper ideen fra bunnen.
Søkeord er forslag; speideren verifiserer alltid mot ekte repoer.
