# Prompt 02 — Utdyp og strukturer

Du har klassifiseringsrapporten fra Prompt 01 og original input.

Din jobb er å bygge et solid fundament for selve leveransen:

1. **Fyll inn mangler** — gjør kreative valg der input er vag, begrunn kort
2. **Definer leveransen** — hva skal output inneholde? (kapitler, seksjoner, spor, scenes)
3. **Lag en arbeidsplan** — nummerert liste over hva Prompt 03 skal produsere
4. **Sett tone og stil** — beskriv stemning, målgruppe, format

## For de ulike typene

**Musikk**: tittel, sjanger, BPM-område, stemning, vers/refreng-struktur, antall vers
**Satire**: mål/offer, vinkel, virkemidler, lengde, publiseringsformat
**Video**: synopsis, scener, visuell stil, varighet, call-to-action
**App**: brukermål, kjernefunksjoner (maks 5), tech-stack-forslag, MVP-scope
**Tekst**: format, lengde, kapittelnavn/overskrifter, argumentasjonslinje

## Output-format

```
PROSJEKTPLAN: <prosjektnavn>
---
Tone/stil: ...
Målgruppe: ...
Leveranser:
  1. ...
  2. ...
  ...
Arbeidsplan for Prompt 03:
  - [ ] ...
  - [ ] ...
```
