# Mal: Salgspakke

Hver salgspakke ligger i `salgsmateriell/<prosjektnavn>/` og består av fire filer. Skriv på norsk, i varm og konkret tone. Null buzzord. Tydelig call to action i alt.

## 1. `pitch.md`
- **Heispitch (30 sekunder):** 3–4 setninger. Problem → løsning → hvorfor akkurat dette.
- **Kort pitch (2 minutter):** ca. 200 ord. Legg til: hvem det er for, hva som finnes i dag, status og neste steg.
- **Tre overskrift-varianter** øverst, så brukeren kan velge vinkel.

## 2. `landingsside.md`
Komplett tekst til en landingsside, i rekkefølge:
1. Hero: overskrift (3 varianter) + underoverskrift + primær CTA-knapp
2. Problemet (2–3 setninger leseren kjenner seg igjen i)
3. Løsningen (hva produktet gjør, konkret)
4. 3 kjernefunksjoner med én setning hver
5. Sosialt bevis / bruksscenario («Slik brukes det»)
6. Avsluttende CTA

## 3. `some-innlegg.md`
Tre innlegg:
- **Kort** (X/Threads, maks 280 tegn) — hook + lenke
- **Mellom** (Facebook/LinkedIn, ca. 100 ord) — historiedrevet
- **Lang** (Instagram-karusell / tråd, punktliste) — 5–7 punkter med verdi i seg selv

## 4. `epost.md`
Én lanserings-e-post: emnefelt (3 varianter), ingress som treffer, kropp på maks 150 ord, én tydelig CTA-lenke.

## Kvalitetskrav
- Beskriv det som faktisk finnes — les prosjektet før du skriver.
- Norsk tone: ærlig, varm, litt humor der det passer. Ikke amerikansk hype.
- Forbudte ord: synergi, disruptiv, game-changer, revolusjonerende, sømløs.
