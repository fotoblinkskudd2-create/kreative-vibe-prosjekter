# Vibe-kort apper

Idéer og konsepter for Vibe-kort apper.

- `prototyper/` – wireframes, mockups og tidlige funksjonelle prototyper.
- `salgsmateriell/` – pitch-decks, skjermbilder og annet materiale for å presentere appen.
- `klar-til-bygg/` – ferdig spesifiserte apper med all info som trengs for å starte utvikling.
