# Høringsnotat om dugnadsplikten

**Premiss:** Hva om dugnadens uskrevne regler ble skrevet ned — i ekte
forvaltningsspråk?

**Format:** Parodi på offentlig høringsnotat (formatet «offentlig dokument»
fra satire-skribentens verktøykasse).

## Bruksområder
- Deles som tekstinnlegg / bilde-karusell i sosiale medier rundt vårdugnadstid (april–mai)
- Kan leses opp som video med tørr byråkratstemme (én statisk «pressekonferanse»-kamera)
- § 4 (Vaffelbestemmelsen) fungerer alene som kort klipp/sitatbilde

## Videreutvikling
- Oppfølger: «Rundskriv om bruk av felles grill»
- Oppfølger: «NOU 2026: Hvem sin tur det egentlig er til å ta oppvasken på jobb»
- Serie: «Direktoratet for frivillighet og annen pålagt aktivitet» som fast satirisk avsender
