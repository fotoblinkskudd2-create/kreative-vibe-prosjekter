# Plan først

Bruk denne før oppgaver som tar mer enn ~30 minutter eller berører mer enn 3 filer.

## Planmal (maks 15 linjer)
```
## Mål
Én setning: hva er sant når vi er ferdige?

## Trinn
1. … (hvert trinn skal ha et verifiserbart resultat)
2. …

## Risiko
- Det mest sannsynlige som går galt + plan B

## Ferdig når
- Konkret, testbar betingelse (ikke «ser bra ut»)
```

## Regler
- Planen skrives FØR første verktøybruk, ikke rekonstrueres etterpå.
- Trinn som ikke kan verifiseres er ikke trinn, det er håp — omformuler.
- Ved kursendring underveis: oppdater planen med én linje om hvorfor.
- Store oppdrag: lagre planen i `herden/planer/<slug>.md` så andre agenter ser den.
