# Dagens sprint — autopilot

Brukeren har gitt deg rattet. Ikke still spørsmål — velg selv, bygg ferdig, rapportér til slutt. Svar på norsk.

## Steg

1. **Les statustavla.** `STATUS.md` viser hva som er gjort og hva som ligger i køen. Les også `ideer/README.md` (topp 10-lista).

2. **Velg 1–3 oppgaver** med best forhold mellom verdi og innsats. Gode kandidater, i prioritert rekkefølge:
   - Halvferdige prosjekter i `STATUS.md` (gjør ferdig før du starter nytt)
   - Neste prosjekt fra topp 10-lista i `ideer/README.md`
   - En ny låtpakke, satiretekst eller prototype fra katalogen
   - Forbedring av en eksisterende prototype (funksjoner fra dens README «videreutvikling»-liste)

3. **Kjør produksjonslinja** for hver oppgave (som i `/nytt-prosjekt`): riktig subagent bygger → `tekstforfatter` lager salgsmateriell for nye prosjekter → `kvalitetssjef` sjekker. Kjør uavhengige oppgaver parallelt med bakgrunnsagenter.

4. **Oppdater `STATUS.md`** — flytt ferdige ting, legg inn nye, oppdater «Neste anbefalte steg».

5. **Commit og push** alt, med beskrivende meldinger.

## Sluttrapport
Kort og konkret: hva som ble levert, hvor det ligger, hvordan prøve det, og hva som anbefales neste økt.
