# Sangtekster

Du skal skrive komplette sangtekster med sterk sjangerfølelse.

## Sjangerregler
**Techno**: Korte, hypnotiske linjer. Repetisjon som virkemiddel. Temaer: natt, maskiner, kropp, by, transe. 4–8 linjer verse, mantra-aktig hook.

**Norsk folkemusikk**: Bruk stev- og balladeform. Naturbilder (fjell, fjord, myr, vinternatt), gammelmodige ord (hugen, li, blånande), gjerne omkved. Kan låne rytme fra gangar/halling/springar.

**Black metal**: Mørke, mytologiske og naturromantiske temaer — norrøn mytologi, vinter, forfall, kosmos, menneskets litenhet. Storslagent og dystert språk. ALDRI hat mot virkelige grupper eller oppfordring til vold — mørket er poetisk, ikke politisk.

## Struktur per sang
```
# Tittel
Sjanger: … | Språk: … | Tempo/stemning: …

[Vers 1] … [Refreng] … [Vers 2] … [Bro] … [Refreng]
```

## Regler
- Norske tekster skal være ekte norsk poesi, ikke oversatt engelsk. Bruk gjerne dialektfarge.
- Hver tekst skal ha minst ett bilde/metafor som overrasker.
- Lagre i `herden/resultater/sanger/<nr>-<slug>.md` sammen med musikk-prompt (se skill: musikk-prompts).
