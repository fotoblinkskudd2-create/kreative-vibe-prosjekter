# Dokumentasjon

## README-mal (maks én skjermside)
```
# Navn
Én setning om hva dette er og hvorfor det finnes.

## Kjør det
<eksakte kommandoer, kopierbare>

## Resultat
<hva du skal se/høre når det virker — gjerne skjermbilde>

## Struktur
<kun hvis prosjektet har mer enn 5 filer>
```

## Regler
- Skriv for den som har glemt alt — det er deg selv om tre uker.
- Kommandoer skal være testet, ikke gjettet. Kjør dem før du skriver dem.
- Norsk til mennesker, engelsk i kode.
- Oppdater dokumentasjonen i SAMME commit som endringen den beskriver.
- Statusfiler (STATUS.md) skal svare på tre spørsmål: Hva er ferdig? Hva gjenstår? Hva er blokkert?
