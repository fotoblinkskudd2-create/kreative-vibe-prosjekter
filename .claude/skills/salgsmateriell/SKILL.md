# Salgsmateriell — komplett salgspakke

Lag en full salgspakke for prosjektet brukeren peker på. Svar på norsk.

## Steg

1. **Les prosjektet grundig.** Prototypen (`prototyper/<navn>/`), låtpakka (`musikk/<navn>/`) eller satireteksten (`satire/<navn>/`). Teksten skal beskrive det som faktisk finnes.

2. **Bruk malen.** `salgsmateriell/MAL.md` definerer strukturen. Se `salgsmateriell/vibe-kort/` for et ferdig eksempel på nivået som forventes.

3. **Skriv pakka** til `salgsmateriell/<prosjektnavn>/`:
   - `pitch.md` — heispitch (30 sek) + kort pitch (2 min)
   - `landingsside.md` — komplett tekst til en landingsside
   - `some-innlegg.md` — 3 innlegg (kort/mellom/lang) tilpasset ulike plattformer
   - `epost.md` — én lanserings-e-post

   For større jobber: deleger til subagenten `tekstforfatter`.

4. **Kvalitet:** Tre overskrift-varianter der malen ber om det. Null buzzord. Tydelig call to action overalt. Norsk tone — ærlig og varm, ikke hype.

5. **Commit og push.**
