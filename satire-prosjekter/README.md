# Satire-prosjekter

Idéer og konsepter for satiriske prosjekter (tekst, video, kunst, o.l.).

- `prototyper/` – utkast og tidlige versjoner av satirisk innhold.
- `salgsmateriell/` – presentasjoner og materiale for å vise prosjektet til andre.
- `klar-til-bygg/` – ferdig spesifiserte prosjekter klare for produksjon/publisering.
