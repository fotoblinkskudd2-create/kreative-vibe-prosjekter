# Ideelle prosjekter

Idéer og konsepter for ideelle (non-profit/veldedige) prosjekter.

- `prototyper/` – tidlige utkast, skisser og funksjonelle prototyper.
- `salgsmateriell/` – pitch-decks, brosjyrer og annet materiale for å presentere prosjektet.
- `klar-til-bygg/` – ferdig spesifiserte prosjekter med all info som trengs for å starte utvikling.
