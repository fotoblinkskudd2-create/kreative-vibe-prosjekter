## Del 2 — Fem produktkonsepter

Se `produktkonsepter.md` for fem detaljerte konsepter som hver kobler ett
eller flere funn fra del 1 til en konkret drone-, smartenhet- eller
produktinnovasjon:

1. **AlbaWing** — dynamisk seilings-drone for ekstrem rekkevidde med
   minimalt energiforbruk (albatross + hvalfinne-tuberkler).
2. **CarapaceGrip** — selvhelende, formtilpassende dronepanser
   (skilpaddeskall + trebark-selvforsegling + blekksprut-kamuflasje).
3. **DesertHarvest** — passiv atmosfærisk vannhøstings-node for
   IoT-jordbruk (Namib-bille + kaktus + termitthaug-ventilasjon).
4. **SwarmSense** — desentralisert sverm-koordineringsprotokoll for
   dronenettverk (slimsopp + ildmaur-flåter + bie-dans).
5. **EchoNav** — passivt, GPS-fritt navigasjonssystem for droner i
   signalfattige miljøer (flaggermus-ekkolokalisering + ørkenmaur-
   stegintegrasjon + trekkfugl-magnetsans).

## Metodikk

Hvert produktkonsept følger samme struktur: biomimikry-grunnlag, teknisk
implementering, use-cases/markedsapplikasjoner, og
prototype-retningslinjer med konkrete neste steg og testkriterier.
